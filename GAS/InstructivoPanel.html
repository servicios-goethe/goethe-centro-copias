Instructivo rapido

Guia operativa para consultar mientras se cargan o procesan pedidos.

Usuario Buscar productos, cargar cantidades, enviar y revisar pedidos propios. v

Uso general

  • Buscar productos por nombre o por ID.
  • Las categorias del catalogo arrancan contraidas; abrir solo la categoria necesaria.
  • Cargar la cantidad directamente en la grilla.
  • El resumen inferior muestra articulos seleccionados y unidades totales.
  • El pedido puede enviarse aunque falte stock.
  • El stock no se muestra al usuario; lo gestiona administracion.

Mis pedidos

  • Permite editar cantidad o eliminar items propios mientras no hayan sido preparados.
  • Si una linea ya fue preparada o entregada, queda bloqueada.
  • Para cambiar una linea bloqueada, solicitar revision a administracion.

Casos especiales

  • Si no encuentra el producto, escribir a copias@goethe.edu.ar.
  • En la terminal de biblioteca se debe completar el mail del solicitante.
El pedido queda registrado aunque no haya stock suficiente. Se preparara lo disponible y se avisara cuando el resto este listo.
Operador Entregar pedidos completos e ingresar reposiciones directas. v

Gestion de pedidos

  • El operador ve una version simplificada del panel.
  • Registrar entrega parcial entrega todo lo disponible y deja el saldo pendiente.
  • Registrar entrega queda para cerrar el saldo cuando todo lo pendiente tiene stock suficiente.
  • No marca preparado/listo ni envia aviso de listo.
  • El mail de retiro se envia al solicitante con el detalle efectivamente entregado.

Ingreso de stock

  • La seccion de reposicion funciona como ingreso directo de stock.
  • Seleccionar productos, cargar cantidades y registrar ingreso.
  • No se usa recepcion de mercaderia ni gestion de compras en este perfil.
El perfil operador se configura en Usuarios_Admin con Perfil = operador. Para una cuenta general de carga, usar Perfil = general.
Admin Gestionar pedidos, compras, productos, recepciones y actividad reciente. v

Vista operativa

  • El bloque de pedido de usuario arranca contraido para priorizar la operacion.
  • Pedidos y lotes se muestran minimizados para trabajar mejor con mucho volumen.
  • Todas las secciones pueden expandirse y contraerse.

Gestion de pedidos

  • Cada linea muestra solicitada, lista, retirada, pendiente, disponible y fisico.
  • Listo: registra cantidad preparada y avisa al solicitante.
  • Retiro: registra lo efectivamente retirado y descuenta stock.
  • Cancelar: anula el saldo pendiente de la linea y pide motivo.
  • Los botones rapidos cargan cantidades disponibles para evitar repetir datos manualmente.
  • Deshacer preparado: vuelve una linea preparada a pendiente si todavia no fue retirada; requiere motivo.

Reposicion y recepcion

  • La reposicion usa la misma busqueda y carga visual que el pedido de usuarios.
  • La referencia u observacion es opcional y puede ser texto o link.
  • El selector Producto recibido ya viene con el producto solicitado.
  • Solo hay que cambiarlo si llego un producto distinto.
  • El stock impacta sobre el producto realmente recibido.

Alta de productos

  • El alta de producto crea el registro del catalogo y su fila de stock inicial.
  • El ID se genera automaticamente desde la categoria.

Perfiles

  • En Usuarios_Admin, Perfil = admin ve todo el panel.
  • Perfil = operador ve solo entrega simple e ingreso directo de stock.
Recomendacion: procesar pedido por pedido o lote por lote, manteniendo cerrados los bloques que no se esten usando.
