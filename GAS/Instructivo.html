Instructivo del Sistema de Inventario

Guia rapida para operar el sistema. Los bloques se pueden expandir y contraer segun el perfil de uso.

Usuario Como buscar productos, cargar cantidades, enviar y revisar pedidos propios. v

Para que sirve

  • Permite solicitar productos del inventario de forma rapida.
  • Se puede pedir aunque no haya stock suficiente.
  • El usuario no ve stock ni faltantes; administracion gestiona disponibilidad y preparacion.

Como hacer un pedido

  • Buscar el producto por nombre o por ID en el campo de busqueda.
  • Abrir la categoria correspondiente; las categorias arrancan contraidas.
  • Cargar la cantidad deseada directamente en la grilla.
  • Revisar el resumen inferior con articulos seleccionados y unidades totales.
  • Presionar Enviar pedido.

Mis pedidos

  • Permite revisar pedidos propios pendientes.
  • Puede editar cantidades o eliminar items solo si no fueron preparados ni entregados.
  • Si una linea ya fue preparada o entregada, queda bloqueada.
  • Para cambiar una linea bloqueada, debe solicitar revision a administracion.

Casos especiales

  • Si no encuentra el producto, debe escribir a copias@goethe.edu.ar.
  • Si usa la terminal de biblioteca, debe completar obligatoriamente el mail del solicitante.
El pedido queda registrado aunque no haya stock suficiente. El equipo administrativo preparara lo disponible y avisara cuando el resto este listo.
Operador Como entregar pedidos completos e ingresar reposiciones directas. v

Perfil operador

  • El perfil operador se configura en la hoja Usuarios_Admin con Perfil = operador.
  • Ve una pantalla simplificada para entrega de pedidos e ingreso directo de stock.
  • No ve recepcion de mercaderia, alta de producto ni actividad reciente.

Entrega de pedidos

  • Abrir el pedido pendiente.
  • Revisar si todas las lineas tienen stock suficiente.
  • Registrar entrega parcial entrega todo lo que tenga stock y deja el saldo pendiente.
  • Registrar entrega se usa para cerrar el saldo cuando todo lo pendiente tiene stock suficiente.
  • No se marca preparado/listo y no se envia aviso de listo.
  • El sistema envia al solicitante el mail de retiro con el detalle efectivamente entregado.

Ingreso de stock

  • Entrar a Ingreso de stock.
  • Buscar productos y cargar cantidades recibidas.
  • Presionar Registrar ingreso.
  • El stock se actualiza directamente y queda movimiento registrado.
Este perfil esta pensado para entrega personal de pedidos y reposicion fisica de stock, sin gestionar compras.
Admin Como gestionar pedidos, compras, productos, recepciones y actividad reciente. v

Vista general

  • Al ingresar, el bloque de pedido de usuario aparece contraido para priorizar la operacion administrativa.
  • Los pedidos y lotes de compra aparecen minimizados para facilitar el trabajo con muchos registros.
  • Todas las secciones pueden expandirse y contraerse.

Gestion de pedidos

  • Abrir un pedido para ver sus lineas.
  • Cada linea muestra producto, estado, solicitada, lista, retirada, pendiente, disponible y fisico.
  • Las acciones se muestran solo al elegir el modo: Listo, Retiro o Cancelar.
  • Listo: registra cantidad preparada para retirar y envia aviso al solicitante.
  • Retiro: registra la cantidad efectivamente retirada y descuenta stock.
  • Cancelar: anula el saldo pendiente de la linea y requiere motivo.
  • Los botones rapidos cargan cantidades disponibles para evitar repetir datos manualmente; siempre se pueden ajustar antes de procesar.
  • Deshacer preparado: vuelve una linea preparada a pendiente si aun no fue retirada; requiere motivo.

Nueva reposicion

  • Funciona con la misma logica visual que el pedido del usuario.
  • Permite buscar productos por nombre o ID.
  • Se cargan cantidades y, si hace falta, una referencia u observacion opcional.
  • Al enviar, se registra la solicitud de compra y se notifica al responsable.

Recepcionar mercaderia

  • Los lotes se abren solo cuando hace falta procesarlos.
  • El selector Producto recibido viene preseleccionado con el mismo producto solicitado.
  • Solo debe cambiarse si llega un producto distinto.
  • La recepcion puede ser parcial o total.
  • El stock impacta sobre el producto realmente recibido.

Alta de productos

  • Permite crear productos nuevos desde el panel admin.
  • El sistema genera el ID automaticamente desde la categoria.
  • Al crear el producto tambien se crea su fila de stock inicial.
  • El sistema bloquea IDs o nombres duplicados.

Perfiles

  • La hoja Usuarios_Admin puede tener columnas Email y Perfil.
  • admin: acceso completo al panel.
  • operador: acceso simplificado a entrega e ingreso directo de stock.
  • general: cuenta compartida que debe ingresar nombre, apellido y mail del solicitante.
  • Si la hoja queda con una sola columna de mails, esos usuarios se consideran admin.

Actividad reciente

  • Muestra acciones administrativas y cambios recientes.
  • Permite revisar usuario, fecha y descripcion de cada movimiento.
Recomendacion operativa: trabajar siempre pedido por pedido o lote por lote, usando los bloques contraidos para mantener una vista limpia cuando hay muchos pendientes.
